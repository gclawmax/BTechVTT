# BattleTech Quick Start --- Combat Rules

Source: Beginner Box Quick-Start Rules.

## Weapon Attack Phase

Combat begins only after all 'Mechs complete movement.

For an attack: 1. Attacker must have line of sight. 2. Target must be
within weapon range. 3. Target must be within the weapon's firing arc.
4. Calculate the modified Target Number using GATOR. 5. Roll 2D6. 6. On
a hit, determine hit location and apply damage.

## Attack declaration

-   Attacks are declared before attacks are resolved.
-   The side that lost initiative declares first.
-   The side that won initiative declares second.
-   A player may declare no attacks.
-   A declared attack cannot be replaced with a different target if it
    becomes impossible.
-   Weapons are fired individually.
-   Each weapon can be fired once per turn.

## GATOR

Modified Target Number =
`Gunnery + Attacker Movement + Target Movement + Other/Terrain + Range`

Base Gunnery is normally 4 in these Quick-Start Rules unless a record
sheet/card specifies otherwise.

## Attack movement modifiers

-   Stationary: +0
-   Walked: +1
-   Ran: +2
-   Jumped: +3

## Target movement modifiers

Based on hexes moved: - 0--2: +0 - 3--4: +1 - 5--6: +2 - 7--9: +3 - 10+:
+4

If the target jumped, add +1 in addition to the hexes-moved modifier.

## Terrain

-   Target in Light Woods: +1.
-   Target in Heavy Woods: +2.
-   Intervening Light Woods: +1 each.
-   Intervening Heavy Woods: +2 each.
-   3+ points of intervening woods block LOS.

## Range

-   Short: +0
-   Medium: +2
-   Long: +4
-   Beyond long range: cannot hit.

## To hit

-   Roll 2D6.
-   Result \>= modified Target Number = hit.
-   Target Number \> 12 = automatic miss.
-   Target Number \<= 2 = automatic hit.
